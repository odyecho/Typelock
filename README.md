# Typelock

> macOS 输入法锁定应用，防止输入法自动切换，让用户始终保持偏好的输入状态

## 项目简介

Typelock 是一款专为 macOS 设计的输入法锁定工具。它解决了 macOS 系统中输入法经常自动切换的问题，让用户能够锁定自己偏好的输入法，提升打字体验。应用以状态栏工具形式运行，轻量、常驻、零干扰。

## 核心功能

- 🔒 **输入法锁定**: 防止系统自动切换输入法
- 👀 **实时监控**: 精确捕获所有输入法切换事件，低资源占用
- 📱 **状态栏应用**: 轻量级常驻，支持点击 / 双击 / 右键多种交互
- 🔔 **智能通知**: 锁定 / 解锁时即时提醒，可按需关闭或调整时长
- ⌨️ **自定义快捷键**: 全局快捷键支持，含冲突检测
- 🎨 **主题系统**: 跟随系统 / 浅色 / 深色三种模式
- ⚙️ **设置导出**: 支持将设置导出为 JSON 文件，方便备份

## 技术栈

- **开发语言**: Swift 5.9+
- **UI 框架**: SwiftUI + AppKit
- **核心 API**: Carbon Framework (TIS)、Accessibility API、NSStatusBar
- **系统要求**: macOS 12.0 (Monterey) 或更高版本
- **权限需求**: 辅助功能权限

## 安装

### 系统要求

- macOS 12.0 (Monterey) 或更高版本
- 支持 Intel 和 Apple Silicon (M1/M2/M3)
- 辅助功能权限（首次启动时自动引导授权）

### 下载安装包（推荐）

1. 前往 [Releases](../../releases/latest) 页面下载最新版 `Typelock.pkg`
2. 双击运行安装包，按向导完成安装
3. 启动 Typelock，按提示授予辅助功能权限

### 手动安装（拖拽方式）

1. 前往 [Releases](../../releases/latest) 页面下载 `Typelock.app.zip`
2. 解压后将 `Typelock.app` 拖拽到「应用程序」文件夹
3. 启动应用并授予辅助功能权限

### 从源码编译

```bash
# 克隆仓库
git clone https://github.com/your-username/typelock.git
cd typelock

# 生成 Xcode 项目（需要安装 XcodeGen）
brew install xcodegen
xcodegen generate

# 在 Xcode 中打开项目并编译
open Typelock.xcodeproj
```

> **注意**: 当前版本尚未通过 Apple 公证，首次运行需在「系统设置 → 隐私与安全性」中手动允许。

## 使用指南

### 基本操作

1. **锁定 / 解锁输入法**: 单击状态栏图标 → 在快速操作面板中点击「锁定」按钮；或双击图标直接切换锁定状态
2. **快速操作面板**: 单击状态栏图标打开，显示当前输入法状态和常用操作
3. **设置**: 右键点击状态栏图标 → 选择「设置」；或长按图标直接打开

### 快捷键（默认，均可在设置中自定义）

| 操作 | 快捷键 |
|------|--------|
| 锁定 / 解锁输入法 | `Ctrl + Option + L` |
| 显示快速操作面板 | `Ctrl + Option + T` |
| 打开设置 | `Ctrl + Option + ,` |
| 刷新输入法列表 | `Ctrl + Option + R` |

### 手势操作（状态栏图标）

| 手势 | 操作 |
|------|------|
| 单击 | 显示快速操作面板 |
| 双击 | 快速切换锁定 / 解锁 |
| 右键 | 显示菜单 |

### 进阶功能

- **主题切换**: 在「设置 → 通用 → 界面设置」中选择跟随系统、浅色或深色主题
- **状态栏图标样式**: 可在通用设置中选择自适应、浅色、深色或彩色图标
- **隐藏状态栏图标**: 可在通用设置中关闭图标（关闭后通过 `Ctrl+Option+T` 唤起面板）
- **设置导出**: 在设置窗口右上角菜单中可将配置导出为 JSON 文件
